Inclusion–exclusion: 6-bit strings containing 000 or 111

BSC129 Discrete Mathematics · Topic 5 Counting, Week 9 slide 14. All 64 strings of length 6, counted case by case. Use the buttons or ← → keys.

A = strings with 000,   B = strings with 111
|A ∪ B| = |A| + |B| − |A ∩ B|
Split A by where the first 000 starts:
  start 1:   000xxx    23 = 8
  start 2:   1000xx    22 = 4
  start 3:   x1000x    2 × 2 = 4
  start 4:   xx1000    22 = 4
|A| = 8 + 4 + 4 + 4 = 20
Swap 0 ↔ 1:   |B| = |A| = 20
A ∩ B = {000111, 111000},   |A ∩ B| = 2
|A ∪ B| = 20 + 20 − 2 = 38

Split by the first 000: every string in A falls into exactly one case, so the four cases can simply be added (sum rule).

The bit just before the run is forced to 1: if it were 0, the 000 would start one place earlier and the string would belong to an earlier case.

Counting "a 000 at position i" overcounts: 4 × 8 = 32, not 20, because strings like 000000 contain 000 more than once.

Use symmetry and check the length: swapping 0 ↔ 1 gives |B| = |A|; A ∩ B needs 3 + 3 = 6 bits, so only 000111 and 111000.
