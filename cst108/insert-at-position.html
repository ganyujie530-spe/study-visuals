insertAtPosition: stop one node early

CST108 Programming Practice · Topic 3-2 Linked List. insertAtPosition(&head, 25, 3) on 10 → 20 → 30 → NULL. Use the buttons or ← → keys.

insertAtPosition(&head, 25, 3);   // in main
void insertAtPosition(Node** head, int value, int position) {
    if (position < 1) { ...; return; }
    if (position == 1) { insertAtBeginning(head, value); return; }
    Node* temp = *head;
    for (int i = 1; i < position - 1 && temp != NULL; i++)
        temp = temp->next;
    if (temp == NULL) { ...; return; }
    Node* newNode = malloc(...); newNode->data = value;
    newNode->next = temp->next;
    temp->next = newNode;
}

Why position - 1: to insert at position p, temp must stop on node p - 1, because that node's next is the one that changes. The loop moves temp position - 2 times.

Order matters: newNode->next = temp->next first, then temp->next = newNode. The other way round loses 30 and everything after it.

position == 1 has no node before it, so head itself must change: that case is handed to insertAtBeginning.
