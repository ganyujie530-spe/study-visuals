insertAtBeginning: why Node** head

CST108 Programming Practice · Topic 3-2 Linked List. insertAtBeginning(&head, 5) on 10 → 20 → NULL. Addresses like 0x100 are made up for the example. Use the buttons or ← → keys.

insertAtBeginning(&head, 5);   // in main
void insertAtBeginning(Node** head, int value) {
    Node* newNode = (Node*)malloc(sizeof(Node));
    newNode->data = value;
    newNode->next = *head;
    *head = newNode;
}

Two different heads: the function's head holds the ADDRESS of main's head (0x100). *head is main's head itself, so *head = ... changes main's head.

Why not Node* head: the function would get a copy of main's head; changing the copy does not change main's head, and the new node is lost.

Order matters: newNode->next = *head first, then *head = newNode. Reversed, *head already points to newNode, so newNode would point to itself.

Empty list: if main's head is NULL, the same code gives newNode->next = NULL, which is correct. No special case needed.
