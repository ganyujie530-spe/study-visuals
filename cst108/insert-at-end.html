insertAtEnd: walking temp to the last node

CST108 Programming Practice · Topic 3-2 Linked List. Inserting 20 into 5 → 10 → 7 → NULL. Use the buttons or ← → keys.

Node* newNode = (Node*)malloc(sizeof(Node));
newNode->data = value;
newNode->next = NULL;
 
Node* temp = *head;
while (temp->next != NULL)
    temp = temp->next;
temp->next = newNode;

temp->next != NULL stops temp at the last node, so its next can be changed. temp != NULL would go past it to NULL (used for print and search).

temp, not head does the walking: moving head would lose the start of the list.

Empty list is handled before this part: if *head == NULL, set *head = newNode and return.
